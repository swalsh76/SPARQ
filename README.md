# SPARQ

**Systematic Prediction-market Automated Risk-managed Quoting.**

SPARQ is an automated maker for prediction markets: it quotes at a seconds scale in second-tier markets around a fair value taken from outside or related markets, never leaves stale quotes, and stays out of the races that professional firms win in milliseconds. It is the successor of KAPS, whose edge study closed with a no-go and whose code it starts from.

Status: being set up (slice S0). No order is sent without the owner's go-ahead.
